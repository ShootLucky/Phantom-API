Phantom

Lua API Documentation

Introdução

Phantom proporciona um poderoso mecanismo de scripts Lua com uma API completa para:

  • Manipulação de objetos de jogo através do sistema de instâncias
  • Desenho de baixo nível com formas, texto e linhas
  • Widgets UI interativos e menus
  • Serviços para players, workspace, lighting e muito mais

Lua Virtual Machine

Gerenciamento do motor Lua e execução de scripts.

bool initialize() VM

Inicializa a Lua VM. Deve ser chamado antes de executar qualquer script.

Retorna: true se bem-sucedido

if (lua_vm::initialize()) {
    // VM está pronta
}
bool is_ready() VM

Verifica se a Lua VM está inicializada e pronta.

Retorna: true se pronta

bool execute_string(const std::string& script, const std::string& chunk_name = "lua_script") VM

Executa código Lua de uma string.

Parâmetros: script (código Lua), chunk_name (nome para debug)

lua_vm::execute_string("print('Hello, Lua!')");
lua_vm::execute_string("x = 42", "meu_chunk");
bool execute_file(const std::filesystem::path& file_path) VM

Executa código Lua de um arquivo.

Parâmetros: file_path (caminho para arquivo .lua)

void on_frame(float delta_time) VM

Chamado a cada frame. Coloque isto no seu game loop.

while (jogo_rodando) {
    float delta = calcular_delta_time();
    lua_vm::on_frame(delta);
    renderizar_frame();
}

Garbage Collector API

Encontre e modifique valores armazenados no garbage collector do Lua por nome, como estatísticas de armas e outros valores armazenados em tabelas Lua.

getgc

getgc(name?: string | { string }): { table } GC

Varre _G (tabela global), o registry Lua e todas as metatables recursivamente. Quando chamada sem argumentos, retorna todas as entradas com chave string encontradas. Quando chamada com nomes, retorna apenas entradas cuja chave corresponda a um dos nomes fornecidos.

Parâmetros: name (string ou table de strings, opcional) — nome(s) para buscar. Se omitido, retorna tudo.

Retorna: Array de entradas, cada uma é uma tabela com:

  • key — o nome sob o qual o valor foi encontrado
  • value — o valor atual (number ou string, se aplicável)
  • type — o tipo do valor (number, string, boolean, table, function, userdata, ...)
  • addr — endereço de memória do valor

O mesmo nome pode ser armazenado em vários lugares, então múltiplas entradas são normais. Retorna uma tabela vazia se nada for encontrado.

-- Todas as globais + registry
local all = getgc()
for _, entry in ipairs(all) do
    print(entry.key, entry.type)
end

-- Buscar uma única chave
local results = getgc("FireRate")
for _, entry in ipairs(results) do
    print(entry.key, entry.value, entry.type)
end

-- Buscar múltiplas chaves
local results = getgc({ "FireRate", "SpreadAngle", "MagAmmo" })
for _, entry in ipairs(results) do
    print(entry.key, "=", entry.value)
end

setgc

setgc(key: string, value: Any): int GC

Define todos os valores garbage-collected armazenados sob key para value, fazendo varredura no collector a cada chamada. Passa uma tabela para definir múltiplas chaves de uma vez. Apenas valores cujo tipo corresponde a value são alterados.

Retorna: Número de valores definidos

-- Singular
setgc("FireRate", 0)

-- Grupo
setgc({
    FireRate = 0,
    SpreadAngle = 0,
    CameraRecoilMult = 0,
    MagAmmo = 999999
})

applygc

applygc(cache: table, key: string, value: Any): int GC

Igual ao setgc, mas aplica a um cache retornado por getgc em vez de fazer varredura novamente. Chame getgc uma vez e reutilize o cache com applygc ao definir valores repetidamente, como dentro de um loop ou para valores que o jogo continua redefinindo.

Parâmetros: cache (table do getgc), key/value ou table de key/values

Retorna: Número de valores definidos

Rode getgc novamente para atualizar o cache se os valores forem reconstruídos, por exemplo ao respawnar ou trocar de arma.

local cache = getgc({ "FireRate", "SpreadAngle", "MagAmmo" })

-- Singular
applygc(cache, "FireRate", 0)
applygc(cache, "MagAmmo", 999999)

-- Grupo
applygc(cache, { FireRate = 0, SpreadAngle = 0, MagAmmo = 999999 })

Sistema de Instâncias

Modelo de objeto hierárquico para organizar objetos do jogo. Todos os objetos herdam de instance.

Propriedades Básicas

std::string get_name() const Instance

Obtém o nome da instância.

local player = workspace:FindFirstChild("Player1")
print(player:GetName())  -- Output: Player1
void set_name(const std::string& name) Instance

Define o nome da instância.

std::string get_class_name() const Instance

Obtém o nome da classe.

Relacionamentos Parent-Child

std::vector<std::shared_ptr<instance>> get_children() const Instance

Obtém todos os filhos diretos.

local children = workspace:GetChildren()
for _, child in ipairs(children) do
    print(child:GetName())
end
std::shared_ptr<instance> find_first_child(const std::string& name) const Instance

Encontra o primeiro filho direto por nome.

local player = workspace:FindFirstChild("Player1")
std::shared_ptr<instance> find_first_descendant(const std::string& name) const Instance

Encontra o primeiro descendente em qualquer profundidade.

Atributos

void set_attribute(const std::string& key, const attribute_value& value) Instance

Define um atributo. Tipos: bool, double, string, null.

player:SetAttribute("health", 100.0)
player:SetAttribute("team", "red")
player:SetAttribute("active", true)
std::optional<attribute_value> get_attribute(const std::string& key) const Instance

Obtém um valor de atributo.

local valor = player:GetAttribute("health")
if valor then
    print("Saúde: " .. valor)
end

Drawing API

Primitivos de desenho de baixo nível para renderizar na tela.

std::shared_ptr<drawing_object> create_object(const std::string& type_name) Drawing

Cria um objeto desenhável.

Tipos: "square", "text", "line"

-- Criar um quadrado
local box = drawing.create_object("square")
box.position.x = 100
box.position.y = 100
box.size.x = 50
box.size.y = 50
box.color = {r=1, g=0, b=0, a=1}
box.filled = true
std::shared_ptr<drawing_object> find_object(int object_id) Drawing

Encontra um objeto desenhável por ID.

bool remove_object(int object_id) Drawing

Remove um objeto desenhável.

void render_all() Drawing

Renderiza todos os objetos visíveis.

void clear_all() Drawing

Remove todos os objetos desenhados.

Propriedades de Objects

position

Coordenadas X, Y

size

Largura e altura

color

Cor RGBA (0-1)

thickness

Espessura de linha

filled

Preencher forma

z_index

Ordem de desenho

Exemplos de Código

Modificar Estatísticas de Arma via GC

-- Buscar valores no garbage collector
local cache = getgc({ "FireRate", "SpreadAngle", "MagAmmo" })

-- Definir valores individuais
applygc(cache, "FireRate", 0)
applygc(cache, "MagAmmo", 999999)

-- Definir vários valores de uma vez
applygc(cache, {
    FireRate = 0,
    SpreadAngle = 0,
    CameraRecoilMult = 0,
    MagAmmo = 999999
})

-- Usar getgc + setgc diretamente (sem cache)
setgc("FireRate", 0)
setgc({
    FireRate = 0,
    SpreadAngle = 0,
    CameraRecoilMult = 0,
    MagAmmo = 999999
})

Trabalhar com Instâncias

-- Obter workspace
local workspace = game:GetService("Workspace")

-- Encontrar player
local player = workspace:FindFirstChild("Player1")
if player then
    print("Encontrado: " .. player:GetName())

    -- Definir atributos
    player:SetAttribute("health", 100)
    player:SetAttribute("team", "red")

    -- Obter todos os filhos
    local children = player:GetChildren()
    for _, child in ipairs(children) do
        print("Filho: " .. child:GetName())
    end
end
